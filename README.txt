como instalar o bot
-1 abre o terminal replit 

-2 caso instalar no replit Apague todo o código que aparecer ➜ COLE TODO O CÓDIGO ACIMA no lugar

-3 No lado esquerdo, clique em Packages ➜ instale essas bibliotecas (pesquise e adicione):

◦ @wppconnect-team/wppconnect

◦ axios

◦ ytdl-core

◦ fluent-ffmpeg

◦ fs

◦ path

-4 Edite só essa linha com SEU NÚMERO no index:

dono: '5521999999999@c.us', // COLOQUE SEU NÚMERO AQUI

-5 Clique em ▶️ RUN (no topo) ➜ vai aparecer um QR Code

-6 Abra seu WhatsApp ➜ Configurações ➜ Aparelhos Conectados ➜ Conectar aparelho ➜ Leia o QR Code

✅ PRONTO! Agora é só ir nos grupos e digitar !menu — tudo funcionando, você controla tudo pelo celular.
